# Архитектура проекта

## Почему монолит?
Для MVP и хакатона монолит быстрее в разработке и проще в деплое. 
Микросервисы требуют настройки сети, оркестрации и увеличивают time-to-market — 
это неоправданно на этапе демонстрации.

## Почему FastAPI?
- Асинхронность из коробки — быстрее обрабатывает запросы к GigaChat.
- Автоматическая генерация OpenAPI-схем (/docs).
- Pydantic-валидация — надёжная типизация на границе API.
- Легче Django для чисто API-задачи (нет ненужного admin, forms, templates).

## Почему React + Vite?
- React — самый востребованный фреймворк, огромное комьюнити.
- Vite быстрее CRA в 10 раз (esbuild vs webpack) — критично для хакатона.
- Компонентный подход позволяет быстро собирать интерфейс.

## Почему SQLite?
- Не требует отдельного сервера — запускается файлом.
- Для демо с 2 ЖК и 24 квартирами производительности хватит с запасом.
- Легко перейти на PostgreSQL позже (SQLAlchemy абстрагирует БД).

## Почему GigaChat?
- Обязательное условие задачи от ГК «ДСК».
- Хорошо работает с русским языком и деловой лексикой.
- Интегрируется с экосистемой Сбера.
